# zkdeal-prover
The RISC Zero CUDA prover: the guest state-transition function, the `zkdeal-r0` host service and the queue-pull agent. Source-published under BUSL-1.1, and also distributed as the runnable image [`zkdeal/prover-cuda`](https://hub.docker.com/r/zkdeal/prover-cuda) whose guest `programId` the source reproduces.
